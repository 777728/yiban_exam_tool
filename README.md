# 校纪校规成绩 · 数据整理前后对比站

一个纯静态单页网站，用于直观展示「原始导出数据」与「结构化汇总」的差异。内容聚焦**前后对比**与**源码可视化**：关键指标概览、整理前/整理后对照、问题处理流程，以及把数据整理程序 `convert_exam.py` 的源代码高亮展示出来。响应式布局，桌面端与移动端均可正常浏览。

## 模板来源
基于 GitHub 开源模板 **Start Bootstrap · Clean Blog** 改造：
- 仓库：https://github.com/StartBootstrap/startbootstrap-clean-blog
- 许可：MIT License（可自由使用与修改）
- 采用其导航、masthead 首屏、响应式栅格与页面结构；在此之上新增 `css/compare.css` 与对比页内容。

代码高亮使用 **highlight.js**（BSD-3-Clause），已本地化。

## 页面结构
1. **首屏**：标题「从一张乱表 → 一套结构化汇总」
2. **关键指标概览**：原始 91 条 / 有效 86 人 / 通过率 90.70% / 分流 5 条 / 覆盖 28 学院
3. **整理前 vs 整理后**：左右对照（原始 CSV 的乱 vs 结构化汇总的清晰）
4. **问题 → 处理 → 结果**：6 类数据问题逐条说明
5. **源代码可视化**：四步流程图（读取 → 清洗识别 → 分流 → 生成汇总）+ `convert_exam.py` 完整源码高亮面板（可滚动、可一键复制）
6. **说明**与页脚

## 如何预览
方式一：直接双击 `index.html` 用浏览器打开。
方式二（推荐，避免个别浏览器本地文件限制）：
```bash
cd exam-data-comparison-site
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765
```

## 展示的数据口径
- 原始记录：91 条（单表）
- 2026 级有效记录：86 人（硕士 + 博士）
- 通过 78 人 / 未通过 8 人，通过率 **90.70%**（≥90 分及格）
- 分流：往届补考 1 人，错考/异常 4 人
- 覆盖学院：28 个
- 产出：1 张通过率统计表 + 28 张学院名单 + 往届/错考名单，共 31 张结构化表

## 隐私说明
页面仅展示**聚合统计**与**脱敏示例**（姓名以 `张*` 形式、学号为示例），不包含任何真实考生个人信息。数据原始文件不随本页面发布。源代码展示的只是整理脚本，运行时仅读取本地 CSV，不上传数据。

## 响应式断点
- 桌面：≥1200px，指标卡 5 列 / 对照双栏 / 流程图 4 列
- 平板：992px 以下，指标卡 2 列、对照上下堆叠、流程图 2 列
- 手机：576px 以下，单列布局、流程图纵向、代码面板横向滚动
